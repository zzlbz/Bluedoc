# BlueDoc 架构

V0.4.0 的页面路径是：首页开始阅读或浏览分类 → 原生分类概览 → 文档阅读。全站共用固定侧栏和顶部位置路径。主题目录是唯一部署单元，不包含核心、测试运行时或数据库。

## 原生数据与路由

`inc/navigation.php` 在每个 PHP 请求内建立一次索引，复用于首页卡片、侧栏、分类概览和面包屑：

1. 从 `Widget\Metas\Category\Rows` 读取分类及原生 permalink，保留后台 `order` 对应的深度优先顺序。
2. 以 `mid` 建节点表，以 `parent` 建邻接表；不以分类名称硬编码层级。
3. 批量读取公开文章元数据与分类关系，建立分类 → CID、CID → 文章映射。另以一次查询读取原生 fields 表中的 bluedocOrder，自定义序号为空或非法时视为未填写。不读取正文，不逐分类或逐文章查询字段。
4. 文章 URL 由 `Widget\Contents\From` 生成，注入与原生 `Category\Related` 相同顺序的分类缓存，支持自定义固定链接。
5. 请求缓存只持续当前请求，没有跨请求持久化缓存；分类与内容修改会在下一次请求生效。站点外部缓存需自行刷新。

整个站点的公开文章元数据会载入请求内存，适用于中小型文档中心；特别大的站点需在后续版本评估索引和导航按需加载。核心自己的文章查询与第三方插件查询不计入主题的批量查询数。

## 树与当前位置

递归渲染分类邻接表，无固定深度限制；节点使用原生 `details/summary`，没有脚本也能折叠。分类下先展示子分类，再列直接关联的文档。分支访问记录阻止损坏关系造成无限递归，分类路径与计数遍历也有循环保护；Typecho 原生分类组件自身仍要求有效的父子关系。

文章高亮根据 CID 判断。默认所有页面显示完整分类树；bluedocNavigationScope=branch 时，文章与分类页才依据关联分类选择顶级分支，首页和独立页面保持全树。所有关联分类沿 parent 上溯并展开，多分类文章可出现在多个关联分支。浏览器记忆各 MID 的开合状态，当前文章祖先优先展开。面包屑选择最深路径，同深度按原生分类顺序。category.php 根据原生 archive slug 找到分类节点并标记当前概览。

深层分支在第五层后停止累加视觉缩进，不截断层级或丢弃节点。分支文档计数包含全部后代，跨分类重复关联按 CID 去重。

## 首页入口

`inc/home.php` 的 bluedocQuickCards 默认读取 children[0] 中前四个原生一级分类。可通过 bluedocQuickParentMid 选择任意父分类，改为读取其前四个直接子分类；后台以路径下拉列表显示选择，不要求手填 ID。旧版平台 MID 设置不再读取，不按名称或别名猜测设备。标题、简介、链接来自真实分类，统一使用通用图标；首页品牌来自后台配置或网站设置。

最新文档通过 bluedocCategoryDocuments 获取该分类及全部后代的公开文章，按索引 created/CID 倒序取三篇并去重。标题进入分类概览，文档链接使用原生文章 URL，没有嵌套链接或逐卡片 SQL 查询。全部分类模块由 bluedocHomeCategories 读取所有真实一级分类，展示其直接子分类与分支文档数，不补出预设分类。

父分类被删除时恢复默认一级分类范围；有效父分类没有子分类时显示空状态，并保留全部分类模块。真实空分类显示暂无公开文档；空站点不制造卡片、分类或链接。分类改名、排序和发布文章在下次请求反映；外部页面缓存需刷新。

精选文档沿用 bluedocPopularCids 按后台 CID 选择并去重；留空或没有有效公开 CID 时使用最新六篇作为候选。推荐只呈现标题、分类和阅读链接，没有博客摘要、时间、作者或评论。

首页分类文章目录取每个一级分类分支按阅读顺序排列的前六篇，使用完整分类页作为更多入口。“开始阅读”优先采用有效公开 bluedocStartCid；否则按后台根分类顺序，选择第一个非空分支的第一篇阅读文档；没有分类时才从公开文档中选择。空站点不生成开始阅读链接。

## 阅读顺序与原生字段

themePostFields(Layout) 在原生文章编辑器提供 bluedocOrder 文本字段，只为文章显示，独立页面没有该字段。保存由 Typecho 自己写入 fields 表，不增设列或表。序号接受 0–999999999，非法或空存量值按未填写处理。

bluedocSortDocuments 和 bluedocReadingDocuments 共用于直接侧栏文档、分类分支列表、首页分类目录和上下篇。manual 模式先排有效序号，同序号与未填序号按 created/CID 升序；oldest/newest 模式按创建时间与 CID 排列并忽略序号。公开索引始终保持最新顺序，因此快速入口和精选推荐的最新候选不受影响。

bluedocAdjacentDocuments 采用当前文章最深关联分类，只从该分类直接公开文档中取前后邻居，不跳到父分类、兄弟分类或其他关联根。单篇分类及未归类文章没有上下篇；多分类选择与面包屑保持一致。

## 分类与阅读模板

`category.php` 是 Typecho 官方原生分类模板入口，显示父分类返回入口、直接子分类与当前分类及全部后代的公开文档列表。列表按 CID 去重，排序与快速导航一致，附所属分类而不输出正文摘要、作者或日期。概览直接使用已建立的索引，因此不受原生博客 pageSize 限制。原生分类分页 URL 同样呈现完整概览，不进行额外分页。

header.php 输出唯一侧栏、打开 workspace 并显示顶部面包屑/位置和配色选择；footer.php 关闭 workspace 并提供全站唯一抽屉遮罩。模板不重复输出侧栏或面包屑。

post.php 和 page.php 共用 partials/document-layout.php，原生正文保留 Markdown、密码表单和权限，右侧目录扫描正文 H2/H3；文章追加同分类上下篇，独立页面不追加。标题下显示分类与 modified 更新时间。comments.php 保留兼容入口但不输出评论。

搜索和其他归档保留 Typecho 原生查询、分页和标题列表，去除正文摘要与发布日期。主题不改变核心搜索算法。

## 响应式与可访问性

桌面侧栏固定并独立滚动，右侧正文与目录采用 grid，顶部位置栏 sticky。<1024px 隐藏正文目录，<768px 所有页面使用抽屉。脚本处理焦点循环、Escape、遮罩、整个 workspace 的 inert 和断点切换；无 JavaScript 时手机侧栏恢复页面内导航。

目录保留唯一已有 ID，修复冲突 ID，支持中文标题和重复标题，滚动时标记章节。CSS/JS 带版本参数；HTML 包含 bluedoc-version 标识，便于区分部署版本与站点缓存。

全部 PHP 入口有根目录访问保护，纯文本与 HTML 属性转义，正文交给 Typecho 原生输出，无插件或外部 UI 框架依赖。

## 配色与阅读增强

color-mode.js 在 head 中提前应用访客选择或系统偏好，用 CSS 变量切换全站颜色。设置保存在 localStorage，存储读取/写入失败均有回退；未运行脚本时 CSS 仍跟随系统。导航状态按站点 URL 与 MID 保存，不存正文数据。

main.js 使用 DOM 节点生成目录、复制按钮和提示框，不将文章标题拼接成 innerHTML。代码复制使用 Clipboard API，缺少该 API 时尝试传统复制，失败提示手动操作。提示框只处理原生引用开头的五种明确标记，兼容 HyperDown 的文本/br 和其他渲染器的 p 容器，保留后续内容；代码块与普通引用不被改写。无 JavaScript 时保留原生代码和引用。当前没有外部语法高亮依赖。
