# BlueDoc 架构

V0.3.1 的页面路径是：首页选择设备或主题 → 原生分类概览 → 文章阅读。主题目录是唯一部署单元，不包含 Typecho 核心、测试运行时或数据库。

## 原生数据与路由

`inc/navigation.php` 在每个 PHP 请求内建立一次索引，复用于首页卡片、侧栏、分类概览和面包屑：

1. 从 `Widget\Metas\Category\Rows` 读取分类及原生 permalink，保留后台 `order` 对应的深度优先顺序。
2. 以 `mid` 建节点表，以 `parent` 建邻接表；不以分类名称硬编码层级。
3. 批量读取公开文章元数据与分类关系，建立分类 → CID、CID → 文章映射。不读取正文，不逐分类查询文章。
4. 文章 URL 由 `Widget\Contents\From` 生成，注入与原生 `Category\Related` 相同顺序的分类缓存，支持自定义固定链接。
5. 请求缓存只持续当前请求，没有跨请求持久化缓存；分类与内容修改会在下一次请求生效。站点外部缓存需自行刷新。

整个站点的公开文章元数据会载入请求内存，适用于中小型文档中心；特别大的站点需在后续版本评估索引和导航按需加载。核心自己的文章查询与第三方插件查询不计入主题的批量查询数。

## 树与当前位置

递归渲染分类邻接表，无固定深度限制；节点使用原生 `details/summary`，没有脚本也能折叠。分类下先展示子分类，再列直接关联的文档。分支访问记录阻止损坏关系造成无限递归，分类路径与计数遍历也有循环保护；Typecho 原生分类组件自身仍要求有效的父子关系。

文章高亮根据 CID 判断。侧栏依据文章关联分类或当前分类选择其顶级根分支，按后台排序渲染这些相关分支，不输出无关一级分类；独立页面仍显示完整树。所有关联分类沿 parent 上溯并自动展开；多分类文章可能在多个关联顶级分支出现。未归类文章显示提示，全部情况均提供浏览全部分类入口。面包屑选择最深关联路径，同深度遵循原生分类顺序。分类路由由 Typecho 先解析验证，`category.php` 根据原生 archive slug 找到导航节点，展开其祖先并标记当前“分类概览”。

深层分支在第五层后停止累加视觉缩进，不截断层级或丢弃节点。分支文档计数包含全部后代，跨分类重复关联按 CID 去重。

## 首页入口

`inc/home.php` 只固定四种设备槽位和图标，卡片数据通过 bluedocDeviceCard 按配置 MID 查找真实分类。标题和描述来自该分类，不使用固定的设备介绍；最新文章通过 bluedocCategoryDocuments 获取该 MID 及全部后代分类的公开文章，按已有索引的 created/CID 倒序筛选三篇并去重。标题链接进入分类，文章链接进入对应原生文章 URL，不创建嵌套链接，也不增加逐设备 SQL 查询。模块同时维护六个推荐主题及其匹配规则、通用主题描述。首页品牌文案来自后台配置或原生站点设置。

分类卡片首先显示真实一级分类，顺序由后台决定；未创建的推荐分类追加为无链接占位。实际分类名称保持不变，主题不写分类数据。已建一级分类的直接子分类可从卡片直接进入。

有效平台 MID 配置优先；明确填写但不存在的 MID 显示准备中，不退回其他同名分类。只有留空才按名称或 slug 匹配，接受数字排序前缀与 Apple 平台别名。同名平台优先采用客户端教程分支。找不到分类时显示准备中，避免错误跳转。

热门教程按后台 CID 选择并去重；留空或没有有效公开 CID 时使用最新六篇作为候选。推荐只呈现标题、分类和阅读链接，没有博客摘要、时间、作者或评论。

## 分类与阅读模板

`category.php` 是 Typecho 官方原生分类模板入口，显示父分类返回入口、直接子分类与当前分类及全部后代的公开文档列表。列表按 CID 去重，排序与设备最新教程一致，附所属分类而不输出正文摘要、作者或日期。概览直接使用已建立的索引，因此不受原生博客 pageSize 限制。原生分类分页 URL 同样呈现完整概览，不进行额外分页。

`post.php` 和 `page.php` 共用 `partials/document-layout.php`。左侧复用同一索引，中间原生正文保留 Markdown、密码表单和权限行为，右侧目录仅扫描正文 H2/H3。标题下显示分类与 modified 更新时间。`comments.php` 保留兼容入口但不渲染任何内容；已有评论及其权限仍由后台管理。

搜索和其他归档保留 Typecho 原生查询、分页和标题列表，去除正文摘要与发布日期。主题不改变核心搜索算法。

## 响应式与可访问性

桌面三栏采用 CSS grid，侧栏和目录独立滚动。分类概览只有导航和内容两栏。<1024px 隐藏文章目录，<768px 使用抽屉。脚本处理焦点循环、Escape、遮罩、背景 inert 和断点切换；无 JavaScript 时恢复页面内侧栏。

目录保留唯一已有 ID，修复冲突 ID，支持中文标题和重复标题，滚动时标记章节。CSS/JS 带版本参数；HTML 包含 bluedoc-version 标识，便于区分部署版本与站点缓存。

全部 PHP 入口有根目录访问保护，纯文本与 HTML 属性转义，正文交给 Typecho 原生输出，无插件或外部 UI 框架依赖。
