# BlueDoc

## 项目定位

BlueDoc 是基于 Typecho 1.3.0 开发的文档型主题。

用于：

- 机场帮助中心
- 软件教程
- 产品文档
- FAQ知识库


## 目标

打造类似：

- GitBook
- MijiDoc
- SaaS帮助中心

的用户体验。


## 技术要求

Typecho:
1.3.0+

PHP:
8.2+

无需额外插件


## 当前阶段

第一阶段仅实现主题基础框架，文件位于 `theme/`，安装与验证记录见 [主题 README](../theme/README.md)。

## 后续规划功能

- 首页文档入口
- 分类导航
- 左侧文档树
- 文章目录
- 深色模式
- 响应式布局
- SEO优化
