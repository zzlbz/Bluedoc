# BlueDoc

## 项目定位

BlueDoc 是基于 Typecho 1.3.0 开发的文档型主题。

用于：

- 机场帮助中心
- 软件教程
- 产品文档
- FAQ知识库


## 目标

打造类似：

- GitBook
- MijiDoc
- SaaS帮助中心

的用户体验。


## 技术要求

Typecho:
1.3.0+

PHP:
8.2+

无需额外插件


## 当前阶段

V0.2 已完成文档信息架构：原生父子分类、文档树、面包屑、首页分类与热门入口、文章目录以及响应式抽屉。文件位于 `theme/`，安装与配置见 [主题 README](../theme/README.md)，验收见 [V0.2 验证记录](v0.2-validation.md)。

## 后续规划功能
