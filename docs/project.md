# BlueDoc 项目目标

BlueDoc 是兼容 Typecho 1.3.0、PHP 8.2 的通用文档中心主题。参考 GitBook、MijiDoc 与 SaaS 帮助中心的信息架构，不硬编码具体服务品牌。

V0.3 以“选择设备 → 浏览分类 → 阅读教程”为主要路径，支持 Windows、Android、iOS、macOS 平台入口和新手入门、客户端教程、订阅配置、软件下载、常见问题、服务说明六个主题。

分类来自 Typecho 原生父子分类，支持任意深度、后台排序、当前文章高亮、祖先展开和多级面包屑。文章为桌面三栏阅读布局、移动抽屉和 H2/H3 自动目录。作者、发布时间列表和评论不进入前台文档界面，文章显示所属分类与最后更新时间。

主题独立运行，不依赖插件，不修改核心或站点分类数据。安装见 [主题说明](../theme/README.md)，架构见 [architecture.md](architecture.md)，验证见 [v0.3-validation.md](v0.3-validation.md)。

后续计划：下载组件、深色模式与检索增强。
