# BlueDoc 项目目标

BlueDoc 是兼容 Typecho 1.3.0、PHP 8.2 的通用文档中心主题，参考 GitBook、MijiDoc 与 SaaS 帮助中心的信息架构。

V0.3.2 以“搜索或浏览分类 → 分类概览 → 文档阅读”为主要路径。默认自动展示后台一级分类，快速导航可选择任意父分类的子分类；不硬编码行业、设备、服务品牌或分类名称。

支持原生无限级分类、后台排序、当前文章高亮、祖先展开、多级面包屑、三栏阅读、移动抽屉和 H2/H3 自动目录。文章只显示分类与最后更新时间，取消博客式作者、发布时间列表和评论界面。

主题独立运行，不依赖插件，不修改核心或站点分类数据。安装见 [主题说明](../theme/README.md)，架构见 [architecture.md](architecture.md)，测试见 [v0.3.2-validation.md](v0.3.2-validation.md)。
