# BlueDoc 项目目标

BlueDoc 是兼容 Typecho 1.3.0、PHP 8.2 的通用文档中心主题，参考 GitBook、MijiDoc 与 SaaS 帮助中心的信息架构。

V0.4.0 以“开始阅读或浏览分类 → 分类目录 → 文档阅读”为主要路径，全站共用固定左侧导航与顶部路径。首页自动展示原生分类，快速导航可选择任意父分类的子分类，不硬编码行业或设备。

支持原生无限级分类、文章序号、同分类上下篇、当前文章高亮、祖先展开、多级面包屑、三栏阅读、移动抽屉和 H2/H3 目录。增加配色切换、导航状态记忆、代码复制及提示框；文章只显示分类与最后更新时间。

主题独立运行，不依赖插件，不修改核心、数据库结构或分类数据。排序保存到原生文章自定义字段。安装见 [主题说明](../theme/README.md)，架构见 [architecture.md](architecture.md)，测试见 [v0.4-validation.md](v0.4-validation.md)。

后续计划：下载组件、检索增强和代码语法高亮。
