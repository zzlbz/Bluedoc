# BlueDoc

BlueDoc 是一款基于 Typecho 1.3.0 的现代化文档主题。

定位：

- 产品帮助中心
- 软件使用教程
- 技术文档
- FAQ知识库


## 当前阶段

第一阶段基础框架已放在 `theme/`。安装时将该目录内容复制到 Typecho 的 `usr/themes/BlueDoc/`。

详见 [主题 README](theme/README.md)。

## 规划功能

- 文档中心布局
- 分类导航
- 自动目录
- 响应式设计
- 深色模式
- SEO优化
- 下载组件


## Target

适用于：

- SaaS产品
- 软件官网
- 机场帮助中心
- 技术博客
