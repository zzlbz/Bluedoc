# BlueDoc 0.4.0

兼容 Typecho **1.3.0**、PHP **8.2** 的通用文档中心主题。无需插件、Composer、Node.js 构建或修改核心文件。

## 安装与升级

1. 备份当前主题目录，将本目录全部内容复制到 `usr/themes/BlueDoc/`，确保 `index.php` 位于主题目录第一层。
2. 升级时完整覆盖 PHP、`inc/`、`partials/`、`assets/`；无需迁移数据库。
3. 在 **控制台 → 外观** 启用 **BlueDoc 0.4.0**，在 **设置外观** 保存设置。
4. 清理站点/CDN 缓存并刷新页面。CSS/JS 带 `?v=0.4.0`；源代码应有 `<meta name="bluedoc-version" content="0.4.0">`。同时覆盖新增的 `assets/js/color-mode.js`。
5. **设置 → 阅读** 选择显示最新文章，进入文档首页模板；主题以分类组织首页，不显示博客文章流。

V0.3.2 将设备入口改为通用分类导航。旧版四个平台 MID 设置不再读取；升级后默认自动显示一级分类。希望保留原站设备入口时，在新设置“快速导航分类范围”选择原来的父分类，例如“客户端教程”。首页标题、描述及精选文档 CID 设置沿用原字段。主题不改名、移动、创建或删除后台分类与文章。

V0.4.0 默认全站显示完整文档树，阅读顺序改为序号优先、未填序号按创建时间从早到晚。升级后若希望保持原来的侧栏范围和倒序阅读，可在外观设置选择“仅显示所属分支”和“创建时间从晚到早”。新增排序字段只在编辑文章并保存后写入原生自定义字段，不迁移现有文章。

## 分类组织

直接使用 Typecho **管理 → 分类** 中的父子分类，不要求特定名称。例如：

```text
开始使用
产品指南
├── 账户管理
│   └── 权限设置
├── 项目管理
└── 团队协作
接口文档
资源下载
问题排查
```

- 首页全部分类显示真实一级分类及其直接子分类，顺序遵循后台；没有预设分类占位卡。
- 快速导航默认显示前四个一级分类。选择父分类后显示其前四个直接子分类，任何层级的父分类都可选择。
- 卡片名称、简介、URL 来自原生分类；最新三篇文档包含后代分类，按创建时间/CID 倒序并去重。真实空分类显示“暂无公开文档”。改名或排序在下一次请求生效，站点外部缓存需刷新。
- 所选父分类已删除时恢复一级分类入口；有效父分类没有子分类时显示空状态，全部分类仍可浏览。
- 无分类、无文档的新站显示中性空状态，不生成虚假链接。
- 分类概览包含返回父分类入口、直接子分类、整个分支的公开文档。只显示标题和分类，不显示博客日期、作者或摘要。
- 支持任意层级，没有固定深度限制；实际规模受 PHP/数据库资源限制。深层树第五层以后停止累加缩进。
- 默认完整文档树；选择分支模式后，文章与分类页只显示所属顶级分支，多分类文章保留全部关联分支。首页和独立页面保持完整树。当前文章高亮，祖先优先展开，其他分支开合状态保存在浏览器。面包屑选择最深路径，同深度按原生顺序。
- 首页分类文章目录按阅读顺序显示每个一级分支前六篇文档，并提供完整分类列表入口；按 CID 去重。
- 只索引已发布且已到发布时间的文章，排除草稿、私密和未来内容。密码文档继续使用 Typecho 原生标题与密码表单，不读取正文到首页索引。

## 后台设置

| 设置 | 行为 |
| --- | --- |
| 首页标题、首页描述 | 可选纯文本，留空沿用网站标题/简介 |
| 快速导航分类范围 | 下拉选择原生父分类，默认自动展示一级分类；无需手填 MID |
| 精选文档文章 CID | 最多 12 个正整数、英文逗号分隔，按填写顺序去重展示 |
| 开始阅读文章 CID | 可选，留空或不可公开展示时，按后台根分类顺序选择第一篇阅读文档 |
| 左侧导航范围 | 完整文档树（默认）或文章/分类页仅显示所属分支 |
| 文档阅读顺序 | 文档序号优先（默认）、创建时间从早到晚、创建时间从晚到早 |

精选 CID 留空或全部不可公开展示时，使用最新六篇公开文章；部分有效时只展示有效内容。展示标题、所属分类和阅读链接。

文章编辑器的自定义字段区增加“文档阅读序号”，填写 0–999999999 的整数或留空。序号优先模式下，已填写文档从小到大排列，同序号按创建时间/CID 从小到大，未填写文档放在后面；损坏或非法存量值按未填写处理。字段名为 `bluedocOrder`，保存到 Typecho 原生 `fields` 表，独立页面不显示此字段。

侧栏直接文章、分类聚合列表和首页文章目录使用同一排序。上下篇只选最深所属分类中直接关联的公开文章，不跨到父分类或兄弟分类；单篇分类不显示上下篇。快速导航最新三篇、精选文档最新回退不受阅读顺序影响。

## 阅读与交互

桌面左侧分类树、中间正文、右侧 H2/H3 目录；小于 1024px 隐藏右侧目录，小于 768px 左侧为抽屉。抽屉支持 Escape、焦点循环和关闭后焦点恢复。目录支持中文、重复标题及锚点冲突修复。

所有页面共用固定侧栏、顶部位置路径和配色选择；侧栏放网站名称、搜索、分类树和独立页面。配色支持跟随系统/浅色/深色，浏览器记忆选择；存储不可用时仍可阅读与切换。正文代码块提供复制按钮；复制失败时提示手动复制。

提示框使用普通 Markdown 引用，支持 NOTE、TIP、IMPORTANT、WARNING、CAUTION 五种标记：

```markdown
> [!NOTE]
> 这里填写补充说明。

> [!WARNING]
> 操作前请确认设置。
```

提示框由前端增强，不修改核心 Markdown 解析器，不处理代码块或普通引用。无 JavaScript 时仍显示原生引用和内容。当前版本不内置代码语法高亮库。

文章顶部显示标题、所属分类和原生 `modified` 最后更新时间，不渲染作者、评论或发布时间。`comments.php` 保留兼容入口但不输出内容；评论数据和权限仍由后台管理。独立页面使用阅读布局，搜索与其他归档保留原生查询和分页。

无 JavaScript 时正文、分类入口、搜索和原生树折叠仍可用；手机侧栏退回页面内导航。

## 文件与测试

`index.php` 是首页，`category.php` 是分类概览；`inc/home.php` 负责通用分类卡片与内置 SVG，`inc/navigation.php` 建立分类/文章索引并生成树；`functions.php` 提供原生设置。阅读公共组件位于 `partials/`，样式与交互位于 `assets/`。

从仓库根目录运行：

```sh
php tests/navigation.php
node --check theme/assets/js/main.js
node --check theme/assets/js/color-mode.js
node tests/typecho-smoke.mjs
```

HTTP 检查是只读检查，需要先在隔离 Typecho 站启用 V0.4.0，默认 `http://127.0.0.1:18230/`，可用 `BLUEDOC_BASE_URL` 指定其他测试站。无分类或文档时明确跳过不存在的路由。

完整 [架构](../docs/architecture.md) 与 [验证记录](../docs/v0.4-validation.md) 属于仓库文档。部署只复制 `theme/`，不包含 Typecho 核心、数据库、账号或测试运行时。
